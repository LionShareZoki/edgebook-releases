# Installing Edgebook

Edgebook is a trading journal for Windows 10 and 11. Installing takes about two minutes.

## 1. Download

Open the [latest release](https://github.com/LionShareZoki/edgebook-releases/releases/latest) and download
`Edgebook-Setup-x.y.z.exe` (about 120 MB). Leave the other files there alone.

The installer is too big to sit in this folder, so it always lives under Releases.

## 2. Install

1. Double click the downloaded `Edgebook-Setup-x.y.z.exe`.
2. Windows may show a blue box, **"Windows protected your PC"**. The installer is safe but not signed by a paid
   certificate yet, so Windows does not know it. Click **More info**, then **Run anyway**.
3. Follow the installer: **Next**, choose the folder or keep the default, **Install**, **Finish**.

If an antivirus stops it, allow `Edgebook-Setup-x.y.z.exe` once and run it again.

## 3. Activate (first start only)

Edgebook opens with a screen titled **"This copy of Edgebook is not activated yet"**.

1. Under **1**, click **Copy** next to your computer code (it looks like `1A2B-3C4D-5E6F-7A8B`).
2. Send that code to the person who gave you Edgebook.
3. You get a key back. Paste it under **2** and click **Activate**.

The key works on that one computer. Your journal stays on your computer and is never uploaded.

## 4. Updates

Edgebook updates itself. When a new version is ready, a button in the left menu says so. Click it, or simply close
Edgebook and the update installs.

## If something goes wrong

| What you see | What to do |
|---|---|
| "Windows protected your PC" | **More info**, then **Run anyway**. |
| Nothing happens after double clicking | Wait 20 seconds. Then check that Edgebook is not already open in the taskbar, next to the clock. |
| A white or empty window | Close Edgebook, wait 10 seconds and open it again. |
| "This key was issued for another computer" | Send the new computer code and ask for a new key. Keys are per computer. |
| "Your key has expired" or "This key has been switched off" | Ask for a new key. |
| The installer says Edgebook is running | Close Edgebook, also next to the clock, then install again. |
| Edgebook says "could not start" | Send the file it names (`startup-error.log`) to the person who gave you Edgebook. |
| It does not open at all, no message | Press Windows key + R, type `%APPDATA%\Edgebook` and press Enter. If there is a `startup-error.log`, send it. If not, send a photo of the screen and your Windows version (Settings > System > About). |

## For the person giving out keys

In Edgebook: **Settings**, then **License**, then **Give out a key**. Type a name, paste their computer code, choose how
long it lasts, and copy the key to send back.
